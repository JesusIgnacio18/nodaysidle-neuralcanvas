## App Description

**Transform your sketches into polished wireframes with the power of on-device machine learning.**

NeuralCanvas is a privacy-first design tool that turns your hand-drawn sketches into professional UI wireframes instantly. No cloud uploads, no subscriptions—just pure, local processing on your Apple Silicon Mac.

**Key Features:**

• **Intelligent Sketch Recognition**
Draw freely with your mouse, trackpad, or Apple Pencil. NeuralCanvas uses CoreML and the Neural Engine to recognize UI elements like buttons, text fields, cards, and more.

• **Style Mirror Technology**
Import a screenshot of any UI you admire. NeuralCanvas extracts colors, typography, spacing, and corner radii to apply to your wireframes automatically.

• **Multiple Export Formats**
Export your wireframes as SVG for scalable graphics, PDF for documentation, or PNG/JPEG for quick sharing. All exports maintain crisp quality at any resolution.

• **Privacy First**
Everything happens on your Mac. No internet connection required. No data leaves your device. Your designs stay private.

• **Native macOS Experience**
Built with SwiftUI 6 for macOS 15+, NeuralCanvas feels right at home on your Mac with native controls, keyboard shortcuts, and full Dark Mode support.

**Perfect For:**
- UI/UX designers rapid prototyping ideas
- Developers sketching app concepts
- Product managers visualizing features
- Students learning design principles

**Requirements:**
- macOS 15 (Sequoia) or later
- Apple Silicon Mac (M1/M2/M3/M4)

## Review Notes for App Review Team

NeuralCanvas is a local-first design application that uses CoreML for sketch recognition. Key points:

1. **No network connections**: The app works entirely offline. All ML inference happens on-device using CoreML.

2. **No user accounts**: No sign-in required. User data is stored locally using SwiftData.

3. **Privacy-focused**: No analytics, no tracking, no cloud services.

4. **System requirements**: Requires Apple Silicon Mac running macOS 15+.

5. **Testing the app**:
   - Launch and complete onboarding
   - Create a new project
   - Draw on the canvas
   - Import a screenshot for Style Mirror
   - Export as SVG

Demo account: Not applicable (no accounts needed)
